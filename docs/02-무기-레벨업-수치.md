# 무기 레벨업 상세 수치

무기 8종의 Lv1~8 수치표다. 무기마다 뱀파이어 서바이버즈에서 가장 비슷한 무기를 골라 공격 방식과 레벨별 수치를 그대로 따랐다. 원본 무기는 각 무기 설명 첫머리에 적었다. Lv1이 기본값이고, 모두 패시브 적용 전 수치다. 범위·속도·회전 속도의 %는 기본값 대비 배율이다. 밸런싱 전 초안이며, 프로토타입 관리자 페이지에서 바로 조정할 수 있다.
