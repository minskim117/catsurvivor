# 고양이 도감

도감은 지금까지 놀아준(만족시킨) 고양이를 모아 보는 메뉴다. 고양이마다 만족시킨 횟수가 쌓이고, 횟수가 늘면 친밀도가 올라 보상을 받는다. 로비에서 열 수 있다.

## 도감에 나오는 정보

핵심 정보는 누적 만족 횟수(잡은 횟수)다. 나머지는 그 고양이와 어떻게 놀았는지 보여주는 기록이다.

| 항목 | 내용 | 예시 |
|---|---|---|
| 도감 번호 | 등장 순서대로 매긴 번호 | No.003 |
| 이름·그림 | 고양이 이름과 전신 일러스트 | 우다다 냥이 |
| 분류 | 일반 / 엘리트 / 보스 | 일반 |
| 만족시킨 횟수 | 지금까지 모든 판에서 만족시킨 누적 횟수 | 1,284번 |
| 한 판 최고 기록 | 한 판에서 가장 많이 만족시킨 횟수 | 212번 |
| 친밀도 | 만족 횟수로 오르는 4단계 발바닥 표시 | 발바닥 3개 |
| 가장 좋아한 무기 | 이 고양이를 가장 많이 만족시킨 무기와 그 비율 | 레이저 포인터 (41%) |
| 처음 만난 날 | 처음 만족시킨 날짜와 그 판의 경과 시간 | 2026.11.14 · 02:13 |
| 나에게 준 피해 | 이 고양이에게 받은 누적 피해 | 3,520 |
| 등장 장소·시간 | 나오는 스테이지와 처음 나오는 시간 | 우리동네 등굣길 · 01:30~ |
| 소개 문구 | 성격과 행동을 담은 한두 줄 설명 | 갑자기 멈췄다가 아무 이유 없이 달린다 |

도감 첫 화면에는 전체 누적 만족 횟수와 도감 완성률(등록한 고양이 수 / 전체 고양이 수)을 표시한다.

## 등록 규칙

고양이는 처음 만족시킨 순간 도감에 등록된다. 기록은 판이 끝날 때 한 번에 합산하며, 등교 성공과 지각 엔딩 모두 인정한다.

| 상태 | 조건 | 도감 표시 |
|---|---|---|
| 미발견 | 아직 만난 적 없음 | 검은 실루엣과 "???" |
| 만남 | 화면에 나왔지만 만족시킨 적은 없음 | 그림과 이름만 표시 |
| 등록 | 1번 이상 만족시킴 | 모든 정보 표시, 친밀도 집계 시작 |

- 만족 횟수는 마지막으로 흥분도를 0으로 만든 무기에 잡힌다. '가장 좋아한 무기'는 이 기록으로 계산한다.
- 오이(화면 전체 퇴장)로 사라진 고양이도 만족 횟수에 포함하고, 무기는 '오이'로 잡힌다.
- 15:00에 골골송을 부르며 멈춘 고양이는 만족 횟수에 넣지 않는다. 보스는 직접 만족시켜야 등록된다.
- 결과 화면에 이번 판에서 새로 등록된 고양이와 친밀도가 오른 고양이를 따로 보여준다.

## 친밀도 단계와 보상

만족시킨 횟수가 쌓이면 친밀도가 발바닥 1~4개로 오른다. 보스는 한 판에 1번만 나오므로 기준이 낮다. 보상은 용돈과 꾸미기만 주고 능력치는 주지 않는다.

| 친밀도 | 일반 | 엘리트 | 보스 | 보상 |
|---|---|---|---|---|
| 발바닥 1개 | 1번 | 1번 | 1번 | 도감 등록, 소개 문구 공개 |
| 발바닥 2개 | 100번 | 10번 | 3번 | 용돈 100, 숨은 이야기 한 줄 공개 |
| 발바닥 3개 | 1,000번 | 50번 | 10번 | 그 고양이 테마 꾸미기 아이템 (예: 아기 고양이 가방 고리) |
| 발바닥 4개 | 5,000번 | 200번 | 30번 | 로비에 그 고양이가 놀러 옴, 도감 카드 황금 테두리 |

### 도감 완성률 보상

| 완성률 (1차 기준) | 보상 |
|---|---|
| 25% (3마리 등록) | 용돈 300 |
| 50% (6마리) | 꾸미기 '고양이 도감 배지' |
| 75% (9마리) | 용돈 1,000 |
| 100% (11마리) | 칭호 '동네 고양이 친구'와 꾸미기 '집사 앞치마' |

완성률은 스테이지별로 따로 계산한다. 2차 '공원 지름길'도 같은 구간(3·6·9·11마리)으로 보상하며, 100% 보상은 칭호 '공원 고양이 친구'와 꾸미기 '도토리 머리핀'이다. 수치는 밸런싱 전 초안이다.
