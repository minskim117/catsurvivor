# 냥이를 뚫고 등교하라 — 게임 기획서

## 한눈에 보기

지각 직전의 학생이 등굣길을 막는 고양이 떼를 츄르와 장난감으로 홀리며 15분을 버틴다. 15분이 지나면 학교 정문이 나타나고, 통과하면 등교 성공이다. 쓰러지면 지각 엔딩이다.

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 로그라이트 서바이벌 (자동 공격, 무리 상대) |
| 조작 | 이동만 직접 조작. 공격은 모두 자동 |
| 캐릭터 | 주인공 1명. 시작 무기는 판마다 선택, 외형은 꾸미기로 변경 |
| 한 판 길이 | 15분 (화면 위쪽에 경과 시간 00:00 → 15:00 표시) |
| 성공 조건 | 15:00 생존 → 학교 정문 등장 → 정문 통과 = 등교 성공 |
| 실패 조건 | 체력 0 → 지각 엔딩 |
| 성장 | 레벨업마다 무기·패시브 중 1개 선택 |
| 슬롯 | 무기 4칸 + 패시브 4칸 (각 8종 중 선택) |
| 진화 | 만렙 무기 + 짝 패시브 보유 → 택배상자에서 진화 |
| 톤 | 귀엽고 코믹. 고양이는 쓰러지지 않고 만족해서 골골대며 사라진다 |

폭력 표현 대신 '만족시키기'로 표현한다. 고양이의 체력은 '흥분도'로, 0이 되면 하트(경험치)를 떨구고 떠난다.

## 게임 플로우

한 판은 타이틀에서 시작해 등교 성공 또는 지각 엔딩으로 끝난다. 어느 쪽이든 용돈을 받아 상점에서 강화하고 다음 판을 시작한다.

*(그림: 게임 플로우 · 한 판의 흐름과 메타 루프 · 원본 문서에서 볼 수 있다)*

점선 상자는 플레이 중 계속 반복되는 성장 루프다. 최종 보상에는 차이가 있지만 실패해도 성장이 쌓여, 반복해서 도전하게 만드는 구조다.

## 인게임 핵심 루프와 구조

한 판은 '만족시키기 → 하트 줍기 → 레벨업 → 강해지기'를 15분 동안 반복한다. 시간이 지날수록 고양이가 많아지고 강해진다.

### 핵심 루프

1. 이동하며 고양이를 피한다. 보유한 무기는 각자 쿨다운마다 자동 발동한다.
2. 흥분도가 0이 된 고양이는 하트를 떨구고 떠난다.
3. 하트를 주워 경험치 바를 채운다.
4. 레벨업하면 게임이 멈추고 카드 3장 중 1장을 고른다. (새 무기 / 새 패시브 / 보유 항목 레벨업)
5. 엘리트·보스 고양이가 떨군 택배상자를 열어 추가 업그레이드나 진화를 얻는다.
6. 강해진 빌드로 더 많은 고양이를 상대한다. → 1번으로

### 슬롯과 레벨 규칙

| 규칙 | 내용 |
|---|---|
| 무기 슬롯 | 4칸. 시작 무기 1개는 판 시작 때 직접 선택 |
| 패시브 슬롯 | 4칸 |
| 무기 최대 레벨 | Lv 8 (진화 조건) |
| 패시브 최대 레벨 | Lv 5 (대용량 리필팩만 Lv 2) |
| 레벨업 선택지 | 3장. 메타 강화로 4장까지 |
| 슬롯이 찼을 때 | 보유 중이면서 만렙이 아닌 항목만 선택지에 등장 |
| 모두 만렙일 때 | 용돈 또는 삼각김밥(회복) 선택지만 등장 |
| 리롤·스킵·제외 | 메타 강화로 해금되는 횟수제 선택지 조작 |

### 택배상자 (보물상자)

고양이가 제일 좋아하는 상자를 보물상자로 쓴다. 엘리트와 보스가 떨구며, 열면 보유 항목 1·3·5개가 한꺼번에 레벨업된다. 진화 조건을 채운 무기가 있으면 진화가 우선 적용된다.

### 필드 아이템

길가의 화분과 쓰레기봉투를 부수면 나온다.

| 아이템 | 효과 |
|---|---|
| 하트 (작음·중간·큼) | 경험치. 크기별로 량이 다름 |
| 용돈 동전 | 메타 강화용 재화 |
| 삼각김밥 | 체력 30 회복 |
| 진공청소기 | 화면의 모든 하트 흡수 |
| 오이 | 화면 안 고양이가 깜짝 놀라 모두 퇴장 (보스 제외) |
| 분무기 | 10초간 모든 고양이 정지 |

### HUD

- 상단: 경험치 바, 경과 시간(00:00부터 15:00까지 올라감), 만족시킨 고양이 수, 용돈
- 좌측 상단: 무기 4칸, 패시브 4칸 아이콘과 레벨
- 캐릭터 발밑: 체력 바

## 패시브 8종

패시브는 학생의 등교 준비물이다. 각각 하나의 능력치를 올리고, 무기 하나와 진화 짝을 이룬다.

| 패시브 | 컨셉 | 효과 (Lv당) | 최대 Lv 합계 | 진화 짝 무기 |
|---|---|---|---|---|
| 든든한 도시락 | 밥 먹고 힘내기 | 공격력 +10% | Lv5: +50% | 츄르 |
| 운동화 | 전력질주 등교 | 이동속도 +10% | Lv5: +50% | 깃털 낚싯대 |
| 보조배터리 | 배터리 빵빵 | 지속시간 +10% | Lv5: +50% | 레이저 포인터 |
| 냥이 귀 머리띠 | 고양이 눈에 더 잘 띠름 | 범위 +10% | Lv5: +50% | 캣닢 봉지 |
| 대용량 리필팩 | 1+1 행사 상품 | 투사체 수 +1 | Lv2: +2 | 털실뭉치 |
| 태엽 알람시계 | 지각은 안 돼 | 쿨다운 -8% | Lv5: -40% | 태엽 쥐돌이 |
| 바나나우유 | 아침 대용 | 최대체력 +10%, 초당 회복 +0.1 | Lv5: +50%, 초당 0.5 | 마따따비 향주머니 |
| 자석 필통 | 다 끌어당긴다 | 하트 획득 범위 +25% | Lv5: +125% | 비눗방울 건 |

방어·행운·성장(경험치 배율) 패시브는 2차 업데이트에서 새 무기·진화 짝과 함께 추가한다.

레벨별 상세 수치: 패시브 레벨업 수치

## 진화 조합표

무기가 Lv 8이고 짝 패시브를 1레벨 이상 갖고 있을 때, 07:30 이후 택배상자를 열면 진화한다. 진화 무기는 같은 슬롯을 쓰고, 패시브는 그대로 남는다.

| 무기 (Lv 8) | 짝 패시브 | 진화 무기 | 진화 효과 |
|---|---|---|---|
| 츄르 | 든든한 도시락 | 참치맛 츄르 대포 | 거대한 츄르 덩어리를 관통 발사. 맞은 자리에 츄르 웅덩이가 남아 지속 피해 |
| 깃털 낚싯대 | 운동화 | 바람개비 깃털 | 플레이어 주변 360도 회전 베기. 이동 중에는 회전이 빨라지고 피해 증가 |
| 레이저 포인터 | 보조배터리 | 미러볼 레이저쇼 | 머리 위 미러볼이 사방으로 레이저 점을 쥐어 보냄. 점이 사라지지 않음 |
| 캣닢 봉지 | 냥이 귀 머리띠 | 캣닢 꽃밭 | 장판이 플레이어를 따라다니며 점점 커짐. 위의 고양이는 뒤굴며 제자리에 멈춤 |
| 털실뭉치 | 대용량 리필팩 | 털실 폭풍 | 털실뭉치 여러 개가 회오리치며 화면을 쓸고 지나감 |
| 태엽 쥐돌이 | 태엽 알람시계 | 무한태엽 쥐돌이 | 쥐돌이가 멈추지 않고 영구 공전. 쥐돌이 수 +2 |
| 마따따비 향주머니 | 바나나우유 | 마따따비 숲 | 오라 범위 2배. 만족시킨 고양이 수에 비례해 체력 회복 |
| 비눗방울 건 | 자석 필통 | 블랙홀 비눗방울 | 큰 방울이 주변 고양이를 빨아들인 뒤 한꺼번에 터짐 |

무기와 패시브가 1:1로 짝지어져 있어, 슬롯 4+4로는 한 판에 최대 4개까지 진화할 수 있다. 무기를 고를 때 패시브 슬롯을 함께 계획하는 것이 핵심 전략이다.

### 상위 진화

짝이 되는 진화 무기 2개를 모두 갖고 11:00 이후 택배상자를 열면 하나로 합쳐진다. 합쳐진 무기는 슬롯 1칸만 쓰고, 빈 1칸은 레벨업으로 새 무기를 넣어 채울 수 있다.

| 진화 무기 A | 진화 무기 B | 상위 진화 | 효과 |
|---|---|---|---|
| 미러볼 레이저쇼 | 블랙홀 비눗방울 | 냥냥 디스코 파티 | 비눗방울이 고양이를 모으면 미러볼 레이저가 그 자리에 집중됨 |
| 캣닢 꽃밭 | 마따따비 숲 | 고양이 낙원 | 플레이어 주변이 넓은 낙원이 됨. 들어온 고양이는 멈춰 뒤굴고, 만족시킬 때마다 체력 회복 |
| 털실 폭풍 | 무한태엽 쥐돌이 | 털실 쥐돌이 군단 | 쥐돌이들이 털실을 끌고 화면을 돌아다니며 실에 걸린 고양이를 묶어둠 |
| 참치맛 츄르 대포 | 바람개비 깃털 | 츄르 회오리 | 회전하는 깃털이 츄르를 사방으로 뿌림. 츄르 웅덩이가 플레이어 주위에 계속 생김 |

진화 무기는 각각 한 조합에만 들어간다. 패시브 짝은 그대로 남아서, 새로 넣은 무기는 진화 짝 패시브가 슬롯에 없으면 진화하지 않는다.

## 고양이(적)와 15분 타임라인

고양이는 부비기·꾹꾹이·발목 살짝 물기로 플레이어 체력을 깎는다. 시간이 흐를수록 종류와 수가 늘고, 04:00·07:30·11:00에 보스가, 13:30에 최종 보스가 등장한다.

| 11:00 | 보스 3: 냥아치 대장 턱시도. 이후 상위 진화 가능 |
| 12:30 | 고양이 대이동: 사방에서 포위 |
| 13:30 | 최종 보스: 등교 저지 위원장 왕고양이 |
| 15:00 | 모든 고양이(최종 보스 포함)가 멈춰 골골송 → 학교 정문 등장, 캐릭터가 정문으로 자동 이동 |

맵은 사방으로 끝없이 이어지는 동네 골목길이다. 스테이지는 1차에 '우리동네 등굣길' 하나만 만든다. 2차 스테이지는 넓은 잔디와 나무가 있는 '공원 지름길'이고, 나무 위에서 고양이가 떨어진다.

## 엔딩: 등교 성공 / 지각

15:00에 정문을 통과하면 등교 성공, 그 전에 체력이 0이 되면 지각 엔딩이다. 어느 쪽이든 모은 용돈은 지급해 다음 판을 강하게 만든다.

### 등교 성공

1. 15:00이 되면 남은 고양이가 최종 보스까지 모두 그 자리에 멈춰 골골송을 부른다. 더 이상 피해를 주지 않는다.
2. 화면 앞쪽에 학교 정문이 나타나고, 조작이 잠긴 채 캐릭터가 정문까지 자동으로 걸어간다.
3. 정문에 닿으면 종소리와 함께 교문을 통과한다.
4. 결과 화면: '등교 성공' 도장, 만족시킨 고양이 수, 사용 무기별 기여도, 획득 용돈.

보상: 획득 용돈 전액 + 성공 보너스, 다음 스테이지·시작 무기·꾸미기 아이템 해금.

### 지각 엔딩

체력이 0이 되면 고양이들에게 파묻혀 같이 낮잠에 빠지고, 등교 시간이 지나 종이 울린다. 생존 시간에 따라 엔딩 컷이 달라진다.

| 생존 시간 | 엔딩 컷 |
|---|---|
| 4분 미만 | 집 앞에서 고양이와 녹아움. '오늘은 결석...' |
| 4~11분 | 골목길에서 고양이 더미에 파묻힘. '지각입니다' |
| 11~15분 | 정문이 보이는 곳에서 쓰러짐. '아깝게 지각!' |

보상: 획득 용돈 전액. 성공 보너스는 없다.

문방구 상점에서 '지각 면제 쥐치'를 해금하면 판마다 1회 부활한다. 체력 50%로 일어나며 주변 고양이를 밀어낸다.

## 캐릭터·꾸미기·메타 성장·결정 기록

판이 끝날 때마다 받은 용돈으로 영구 강화를 사고, 새 시작 무기와 꾸미기 아이템을 해금한다.

### 캐릭터: 주인공 1명

주인공은 등교하는 학생 1명으로 고정한다. 판마다 달라지는 것은 시작 무기이고, 외형은 꾸미기로 바꾼다.

### 시작 무기 선택

판을 시작할 때 해금된 무기 중 1개를 골라 무기 슬롯 1칸에 Lv1로 넣고 출발한다. 나머지 3칸은 레벨업으로 채운다. 해금 조건은 시작 무기 선택에만 적용되고, 레벨업 선택지에는 처음부터 8종이 모두 나온다.

| 무기 | 시작 무기 해금 조건 |
|---|---|
| 츄르 | 기본 |
| 깃털 낚싯대 | 기본 |
| 레이저 포인터 | 기본 |
| 캣닢 봉지 | 기본 |
| 털실뭉치 | 아무 무기로 7분 30초 생존 |
| 태엽 쥐돌이 | 태엽 알람시계 Lv5 달성 |
| 마따따비 향주머니 | 고양이 누적 5,000마리 만족 |
| 비눗방울 건 | 첫 등교 성공 |

### 캐릭터 꾸미기

꾸미기는 외형만 바꾸고 능력치는 바꾸지 않는다. 로비의 꾸미기 화면에서 바꾸며, 인게임·결과 화면·엔딩 컷에 그대로 나온다.

| 부위 | 예시 아이템 | 비고 |
|---|---|---|
| 헤어 | 단발, 포니테일, 까치집 머리, 헤어 색 8종 | 기본 제공 |
| 얼굴 | 피부톤, 눈 모양, 볼터치, 안경 | 기본 제공 |
| 모자·머리 장식 | 고양이 귀 비니, 생선 머리핀, 노란 학생 모자 | 탑다운 시점에서 가장 잘 보이는 부위 |
| 상의 | 교복 셔츠, 체육복, 후드티, 고양이 프린트 맨투맨 |  |
| 하의 | 교복 치마·바지, 체육복 바지 |  |
| 가방 | 책가방, 고양이 얼굴 백팩, 츄르 모양 크로스백 | 등에 메서 실루엣이 크게 보임 |
| 신발 | 실내화, 장화, 고양이 발바닥 운동화 |  |
| 액세서리 | 가방 고리 인형, 목도리, 방울 키링 |  |

- **획득:** 문방구 상점에서 용돈으로 구매하거나 업적 보상으로 얻는다. 업적 예시: 첫 등교 성공, 첫 진화, 지각 엔딩 3종 모두 보기.
- **연출:** 결과 화면과 엔딩 컷에 꾸미기가 그대로 나온다. 인게임에서는 맞을수록 옷에 고양이 털이 붙고, 판이 끝나면 초기화된다.
- **구분:** 패시브 아이템과 이름·모양이 겹치지 않게 한다. 예: 패시브 '냥이 귀 머리띠' ↔ 꾸미기 '고양이 귀 비니'.
- **제작:** 탑다운 소형 스프라이트를 부위별 레이어로 교체한다. 모든 파츠는 같은 이동·피격 애니메이션 프레임을 쓴다.

### 메타 성장 (문방구 상점)

- 용돈으로 영구 능력치 구매: 공격력, 최대체력, 이동속도, 획득 범위 등, 판마다 1회 부활(지각 면제 쥐치)
- 용돈으로 꾸미기 아이템 구매 (능력치 없음)
- 선택지 조작 해금: 리롤(다시 뽑기), 스킵, 제외(해당 판에서 등장 금지)
- 레벨업 선택지 3장 → 4장 확장
- 도감: 만난 고양이, 획득한 무기·패시브·진화, 모은 꾸미기 아이템 기록. 고양이 도감 상세: 고양이 도감 · 무기·패시브 도감 상세: 무기·패시브 도감
